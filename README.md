# SaaS Landing Client

Landing page SaaS/Tecnología extraída de la plantilla multi-modalidad `my-ultimate-landing`, lista para personalizar para un cliente.

## Incluye

- Hero, Features, Stats, Pricing, Testimonials, CTA, Contacto y Footer
- Selector de temas (esquina inferior derecha)
- Stack: React 19 + Vite 7 + Tailwind CSS 4

## Empezar

```bash
npm install
npm run dev
```

## Personalización

El contenido principal vive en `src/pages/LandingSaaS.jsx`. También conviene revisar copy hardcodeado en:

- `src/components/Pricing.jsx`
- `src/components/Stats.jsx`
- `src/components/Testimonials.jsx`
- `src/components/Navbar.jsx` / `Footer.jsx` (marca “TuMarca”)
